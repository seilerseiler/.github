## What We Build

- **Geschossflächenmodell (Floor Area Model)**: Proprietary algorithms estimating existing and permissible floor areas for all buildings across Switzerland, updated annually.
- **Bauzonenkapazität Wizards**: Python-based planning tools for automated zoning capacity analysis, densification potential, and land use scenarios.
- **Raumdaten & Spatial Analysis**: Core urban indicators: building density, population capacity, land value models, Innenentwicklung potential.
